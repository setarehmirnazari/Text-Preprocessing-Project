# Text-Preprocessing-Project
Information Retrieval Course Project


Requirements

- Python 3


Run

1. Open terminal in project folder.
2. Run:

python Setareh_Mirnazari.py

3. Enter number of texts.
4. Enter each text.
5. Enter Gold Standard terms (comma-separated).
6. Press Enter to skip Gold.


Output

- Processed terms: "outputs.json"
- Evaluation: Precision, Recall, Extra Terms, Missing Terms


Input Files (Optional)

python main.py input.json gold.json
